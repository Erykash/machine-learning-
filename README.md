# Aprendizado de Máquina | Projetos Acadêmicos

Repositório dedicado aos projetos, exercícios práticos e avaliações desenvolvidos durante minha graduação em **Ciência de Dados pela Universidade Federal do Ceará (UFC)**.

O objetivo é documentar meu aprendizado em Aprendizado de Máquina (*Machine Learning*), explorando diferentes algoritmos, técnicas de classificação e regressão, métodos de conjunto (*Ensemble Learning*), avaliação de modelos e otimização de hiperparâmetros.

Os projetos foram desenvolvidos utilizando Python e bibliotecas voltadas à análise de dados e ao aprendizado de máquina.

## Objetivos do repositório

Este repositório reúne implementações e experimentos relacionados aos principais conceitos estudados na disciplina, incluindo:

- **Árvores de Decisão:** construção e utilização de modelos de classificação.
- **Random Forest:** aplicação de modelos baseados em conjuntos de árvores de decisão.
- **Métodos de Ensemble:** estudo e implementação de AdaBoost, Gradient Boosting e Stochastic Gradient Boosting.
- **Máquinas de Vetores de Suporte (SVM):** aplicação de algoritmos de classificação.
- **Avaliação de Modelos:** análise de desempenho e comparação entre algoritmos.
- **Otimização de Hiperparâmetros:** experimentação com diferentes configurações dos modelos.
- **Seleção de Modelos:** investigação de estratégias para identificar modelos com melhor desempenho preditivo.

## Como executar os projetos

### 1. Clonar o repositório

```bash
git clone https://github.com/Erykash/machine-learning.git
cd machine-learning
```

### 2. Criar um ambiente virtual

```bash
python -m venv .venv
```

Ative o ambiente:

**Windows**
```bash
.venv\Scripts\activate
```

**Linux / macOS**
```bash
source .venv/bin/activate
```

### 3. Instalar as dependências

```bash
pip install -r requirements.txt
```

### 4. Executar os scripts

Acesse o diretório do projeto desejado e execute o arquivo Python correspondente:

```bash
python caminho/do/arquivo.py
```

**Observação:** alguns scripts dependem de bases de dados específicas. Verifique se os arquivos necessários estão disponíveis e se os caminhos estão configurados corretamente antes da execução.
